# Hendry Commercial

Minimum viable commercial home for Jonathan Hendry.

## Local preview
Open `index.html` in a browser.

## GitHub Pages
1. GitHub → Settings → Pages → Deploy from branch → `main` / root.
2. Once live, add the chosen custom domain under Settings → Pages.

## Before public launch
- Buy/confirm final domain.
- Replace temporary Outlook `mailto:` with professional domain email.
- Add company legal details only after incorporation if/when relevant.
- Add privacy/cookie wording only if analytics/forms requiring it are introduced.
